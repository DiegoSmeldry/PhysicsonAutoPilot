# El Físico Remoto (Physics on Autopilot)

Proyecto desarrolado para el hackatlon de Coafina que produce graficas interactivas a partir de los datos open source del Experimento Atlas del CERN.

## Tabla de contenidos

### Descripción

Explora el decaimiento H → 4ℓ con datos reales de ATLAS: pipelines reproducibles para extraer eventos, calcular observables y crear gráficos interactivos que facilitan tanto el análisis científico como la comunicación de resultados.

### Estado
Estado: Alpha — primera versión; API y resultados sujetos a cambios. Versión: v0.1.0
